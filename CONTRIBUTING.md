# Contributing

This project is in an early bootstrap stage.

## Working agreements

- Keep changes focused and explain the user-facing behavior they enable.
- Prefer small commits and runnable increments.
- Update documentation when architecture or workflows change.
- Do not commit secrets, credentials, private media, or personal data.
- Preserve user-authored source material and provenance.
- AI-generated content is a proposal unless a human explicitly approves it.
- Add tests for domain rules and API behavior as features are introduced.

## Before opening a pull request

- Explain the problem and intended behavior.
- Include setup or migration notes when applicable.
- Run relevant tests and formatting checks.
- Note any known limitations.
